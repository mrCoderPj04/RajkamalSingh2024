# SOFO Sync - Mobile App (`@sofo-sync/mobile`)

Mobile application component for **SOFO Sync**. Designed for iOS and Android via React Native / Expo & Progressive Web App (PWA).

## Key Features
- **Camera QR Scanner**: Instant one-tap scanning to connect to any SOFO Sync desktop or web room.
- **Touch-Optimized Whiteboard**: Smooth multi-touch canvas drawing and shape controls.
- **Real-Time Document Viewer/Editor**: Compact mobile layout for quick collaborative edits.
- **Low-Latency P2P Media Stream**: Mobile camera and mic streaming for instant sync sessions.
