# SOFO Sync - Desktop Client (`@sofo-sync/desktop`)

Desktop native wrapper and companion app for **SOFO Sync** built with Electron/Tauri for macOS, Windows, and Linux.

## Key Features
- **Desktop Companion Tray**: Quick QR pairing from system menu bar or tray.
- **Hardware-Accelerated Screen Share**: High FPS display streaming to connected mobile/web peers.
- **Offline Workspace Sync**: Auto-persists documents and whiteboards locally when offline.
