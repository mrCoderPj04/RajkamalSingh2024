# SOFO Sync - Real-Time Collaboration Suite

## Features & Modules

### 1. Dynamic Canvas Whiteboard (`backend/whiteboard`)
- Freehand vector drawing, rectangles, circles, lines, eraser, and color pickers.
- Real-time stroke broadcasting with sub-20ms latency.
- Canvas clear, PNG export, and snapshot persistence.

### 2. Live Document Workspace (`backend/documents`)
- Concurrent multi-user text editor with real-time cursor presence.
- Version tracking and auto-save capabilities.

### 3. File & Media Vault (`backend/upload`, `backend/media`)
- Instant file drop-and-share across paired devices.
- WebRTC video stream & screen share capability.

### 4. SOFO AI Copilot (`backend/ai`)
- Intelligent document summarization.
- In-session question answering and code assistance.
